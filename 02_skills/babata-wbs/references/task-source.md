# 内部任务源契约

本文件只定义 babata-wbs 的存储替换边界。个人规则与汇报语义由 SKILL 和对应 reference 拥有；
任务源适配是内部实现资料，不是独立 Skill、远程服务或插件协议。只有在线操作需要加载。

## 选择与配置

读取 `BABATA_ASSISTANT_HOME/solutions/wbs/runtime/task-source.local.json`（UTF-8 JSON）；
环境变量未配置、文件缺失／无效、版本不支持或 provider 未实现时报告缺口，不猜旧路径或任务源。
当前支持 schema_version=1、provider=feishu；只加载 [飞书实现](providers/feishu.md)。
本机文件保存已确认连接及身份选择，不放业务模板、执行代码或凭据；认证继续由底层工具管理。

配置形状（占位说明，不是可直接使用的连接）：

```json
{
  "schema_version": 1,
  "provider": "feishu",
  "connection": {"base_token": "<private>", "table_id": "<private>"},
  "identity": "user",
  "timezone": "Asia/Shanghai"
}
```

飞书连接两项必须非空；identity 只接受 user／bot，且使用 bot 仍须符合用户明确授权。
时区必须可识别，用户本次明确时区优先。配置选择不是迁移、双写或改变操作者的授权。
读前解析一次源身份，写前核对目标仍属于同一 provider 和连接；不得把其他源的 native ID 复用过来。

## 读取边界

这是 Agent 在工作区中解释的最小数据约定，不强制增加序列化脚本或复制整表。适配实现须能提供：

| 信息 | 必须保留的含义 |
| --- | --- |
| source | provider、数据集身份（飞书为 Base＋Table）；连接细节只保留在私有工作区 |
| observation | 查询范围、用户时区、观察时间、已知源版本；不提供版本就留未知 |
| completeness | 查询是否结束、页数／解析数量、投影字段、缺口；局部不能称全量 |
| task identity | source＋native ID 唯一；业务 ID／标题只是可重复业务值，不能代 native 身份 |
| task values | 业务 ID、标题、优先级、状态、层次、归档、进度、日期、摘要／详情、本地目录、循环／次数、父关系与已有 TOP |
| presence | 每字段区分已投影真实值、已知空值、未投影或无法解释；未知不压成 null／0／未归档 |
| evidence | 保留原字段及解释缺口、原生身份、原始导出／manifest 指针；不改原字节 |

规范化进度为 0–1，0 与空值不同；异常范围报告原值与缺口，不截断或补值。选择项映成业务名称，
多值或未知选项保留原貌；父关系转为同源 native 身份；TOP 返回已登记序号／分母／标记。
不凭 TOP 推断父关系，不把日期当实际进度。源不能表达的字段标为缺口，不能虚构等价语义。
业务层只依赖这些含义，汇报不直接依赖 Base 字段名、select 数组或摘要前缀。

## 写入与回读边界

输入为明确操作（创建／更新）、同源目标、涉及字段最新基线与有授权的最小业务差异。
新建查重覆盖归档，必要分页未结束不能断言无匹配；更新业务 ID 必须先消歧为 native 目标。
只编码本次差异，未涉及字段不清空；清空需明确语义。配置切源后旧基线／旧身份失效，重新读取。

适配前核对字段能力，冲突、未实现字段或基线漂移只停受影响对象；不为凑同一结果静默降级。
每项返回 native 身份、原值与请求差异、写响应，以及最终回读的实际值与匹配情况。
结果保留 changed／unchanged／conflict／failed／unknown，错误注明对象、阶段、可重试性和缺口。
缺配置／工具／权限是依赖失败，分页失败是读取不完整；它们不是空表、无变更或完成。
dry-run 返回请求预览且不提交；真实写超时或状态未知先核对，不重建或重复加计数。
取消时停止新写入，已提交项仍留结果／回读义务；不承诺跨记录事务或无竞态。

## 以后替换任务源

1. 在同一 Skill 的内部 providers reference 实现上述边界，复用现有可用工具；不复制个人规则和模板。
2. 先以脱敏样本核对身份／字段存在性／空值／进度／父子／TOP／统计覆盖，再用明确授权的隔离对象
   验证新工具的真实读取、最小变更及回读；离线样本不能证明新后端可用。
3. 验证后显式更新 provider 选择和连接，业务规则与模板保持不变；旧源不再被自动读取或写入。
   仅改配置不能使尚未实现的 provider 可用；未知 provider 必须停止。
4. 任务迁移如有需要另定范围、身份映射与验收；切换本身不复制数据、不双写、不自动回退。

目前只有飞书实现。此可替换设计不表示已有其他真实后端或运行时加载框架。
