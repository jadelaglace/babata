# 媒体路由与本地门槛

## 1. 盘点

对目标根目录：

- 按扩展名分组计数与总字节
- 每类取：用户点名样本，否则偏小样本
- 标出异常：>200MB 视频、超长竖图、扫描版 PDF、加密文档

## 2. 探针命令（按需）

```bash
ffprobe -v error -show_entries format=duration,size -show_entries stream=codec_type,codec_name,width,height -of default=noprint_wrappers=1 <file>
```

Python 思路：

- 图：`PIL.Image.open` → size/mode
- PDF：`pypdf` 抽字；`pymupdf` 渲页
- DOCX：`python-docx` 段落+表
- XLSX：`openpyxl` 前 30 行 × 12 列预览
- PPTX：`python-pptx` 或 zip 内 `ppt/slides/slide*.xml` 的 `<a:t>`

## 3. 规范化建议参数

| 输入 | 建议 |
|------|------|
| 图送 VL | 最长边 ≤ 2048；PNG/JPEG；去 alpha |
| PDF 页图 | 2x render，再视情况缩到 2048 |
| ASR 音频 | mono, 16 kHz；优先无损 FLAC/WAV；新 route 先试跑 60–180s |
| 视频预览 | 可选 30–60s H.264 低码率；截帧 `-ss` 选有板书处 |
| 文本送 LLM | 先 4k–12k 字符；超长分段或先本地缩略 |

## 4. 路由决策树

```text
有可靠文本？
  是 → 本地保真提取；有使用价值时再选择文本模型做摘要/结构化
  否 → 是音视频？
          是 → 抽音频并选择 ASR adapter（+可选截帧）
          否 → 是图或可渲成图？
                  是 → 选择 OCR/vision adapter
                  否 → 记录无法处理原因
```

## 4.1 C1B 多模态保真层次

对课程资料，先完成内容本质判断；已有 C1A 可以复用，但不是生成 C1B 的固定前置条件。按表达
不可替代性独立判断各类片段；同一对象可以同时产生多种模态：

- 图片：公式、图表、PPT 图示、乐谱和其他关键视觉内容，直接从 PDF/PPT/视频帧裁取图片。
- 音频：音乐、音色、环境声、SFX 或演奏有独立价值时，从视频抽取或裁剪音频，不保留整段视频。
- 视频：手势、触键、UI 操作、复杂镜头、动画、3D 材质变化或真正高光依赖连续时间时，裁剪视频片段。
- 附件：当文本、图片、音频和视频仍无法表达对象的必要属性时，抽取必要模型、工程、原型、数据集、
  字体、材质包或源代码部分；附件可以和前三类并存。

每一层都允许裁剪、抽取和转码。没有必要的新增媒体时，C1B 可以只保留清洗后的文字本质。来源
页码、时间段、裁剪框或内部路径能记就记；无法独立回链时，
片段仍可作为 C1B 候选。

## 5. 成本与范围控制

- 新目录：每类 1 样本
- 通过后再：按周次/科目分批
- 视频全长：按已授权范围处理；只有完整时长成功后才能宣告 transcript 完成
- 同一原件已有合格派生物：默认跳过，除非用户要求重跑
