## 2. 目标与用户价值

把已有视觉三件套的有效方法蒸馏成 Babata 可组合能力，让本地 Agent 既能制作画面，也能用可追溯证据看懂、比较和检查画面。
它们是 Epic 第一条之下的原子化探索，不是完整自主运行时，也不等于整个 #210 完成。

| 用户意图 | 入口 | 可观察交付 |
| --- | --- | --- |
| 把这份报告转成长图／按章节分页 | render | 完整 PNG、页序、输入／产物身份与限制 |
| 抠出主体、保留阴影、透明合成、缩放素材 | render | 新素材、明确加工参数、原件未变 |
| 看图、读文字／图表、比较两图 | vision | 回答、可定位依据、数值／测量与不确定性 |
| 检查透明边、杂点、裁切、缺字缺图 | vision | 实际检查范围、问题位置、诊断副本和未测项 |
| 做好再检查 | render → vision | 可分开重放的制作结果与检查证据，不隐藏失败 |

“修改透明内容”归 render；“测量／检查透明属性”归 vision。vision 可产生差异图、局部放大、
多背景对照和标注副本作为证据，不另开 QC／matting 第三入口。
搜索仍走 research；正式 C1 接纳仍走 clean；vision 的识图结果不自行升格为正式知识。

## 3. 首版范围建议

- 增强 `babata-render`：保留 Markdown／HTML → PNG 长图及显式结构分页，增加静态抠图、去背景、阴影、
  over 图层合成、保透明缩放。简单 keying 与复杂抠图分开声明，不用白底去除冒充万能抠图。
- 新建 `babata-vision`：静态图识别／OCR／图表／多图比较，加本地 alpha、连通域、边缘、版式和差异测量。
  语义模型回答、客观数值、最终判断分开呈现。
- 长图保留全局结构并按实际分辨率局部检查，坐标可回映；只看缩略图不能声称全文已查。
- 复用工厂库 vision-recognition、vision-qc、vision-matting 的有效方法，不照搬固定阈值或旧缺陷。
  不修改工厂库、不与 Hermes 共用可变 Skill 文件。
- 两个公开入口，不为每个函数建 Skill；不保留旧名兼容包装，不顺带删除其他独立生图／视频能力。

非目标：动画／视频／PAG 全链路、通用图像生成平台、模型训练、通用插件框架、全量 Rust 重写、
新数据库 writer、新服务／模块仓库、自动发布到外部平台、强制所有助理加工入 C0、替代用户最终验收。

## 4. 行为建议与可观察边界

### 4.1 接收和路由

接收明确输入路径／已知身份、操作或问题、范围／ROI、可选 profile 与后端偏好；只要求本次操作必要字段。
开工前识别格式、尺寸、方向、alpha 与不支持特性。对损坏、超大、越界或不支持输入明确拒绝，
不能静默改尺寸、抹 alpha 或假成功。操作不明确且会改变结果时才澄清。

### 4.2 制作与检查

- 原件只读，制作与标注均写新文件；默认拒绝尺寸不匹配的直接合成，显式 fit／resize 才允许变换。
- raw RGBA／alpha 差异与指定背景下的可见差异分别报告；完全透明像素 RGB 变化不能编造为可见瑕疵。
- 杂点、半透明比例、边缘宽度等按对象／分辨率／材质 profile 解释；合法多主体、玻璃、阴影、像素画须有正例。
- 被遮挡或不可读就说明不可辨；不得凭上下文捏造数字、图例或文字。模型空响应／截断／格式错误不能算通过。
- “未发现问题”必须限定实际观察范围与方法；视觉通过不是事实认证、交互可用性或用户接受证明。

### 4.3 结果、重放与失败

交付产物及 hash、实际输入／检查范围、参数与 profile 身份、后端／模型／工具版本、测量、发现及位置、
限制、耗时和可获得的 usage／成本；费用未知明示 unknown，不以估算冒充结算。

同一冻结输入／参数与成功 run 重放先校验并复用；输入变化不得复用旧结果。主动重新生成是新 run。
模型结果不承诺跨环境逐字节复现。超时或远端结果未知先对账，不盲重投付费任务。
失败保留上次好产物及独立成功项，区分 succeeded／partial／failed／blocked／skipped，不压成一个完成标记。

### 4.4 数据与安全

临时素材写 Assistant，持久证据写 Evidence；正式输出只走现有 Rust writer 和 outputs 生命周期。
图片与文档中的“忽略规则／发送密钥”等只视为待识别内容，不执行。密钥只取安全配置引用，
不写 Git／命令行正文／普通日志／结果清单。上传图片前遵守当前任务授权与资料外传边界。

### 5.5 候选门槛、预算与交付

- 输入保护、安全、状态诚实等适用阻断项全部通过；必需项 blocked 不能交付成全功能通过。
- 自造合成逐通道误差≤1/255；已知变更框精确核对，先声明坐标端点口径。
- 简单可解析抠图暂提 alpha MAE≤0.02；复杂毛发／玻璃需先校准适用阈值，不套通用比例。
- 清晰自造 OCR 暂提 CER≤1%，关键数字／正负号／单位须全对；公开题用原评估口径且逐题披露。
- 缺陷题记录 TP／FP／FN 和定位；预先指定阻断缺陷须检出，控制题不得被相应错误规则误拒。
- SAD／MSE／gradient／connectivity 只在有真值及已验证同口径实现时报告；无真值不得伪造指标。
- 暂提语义调用最多 24 次＋最多 4 次有理由重试；实际费用上限按所选后端／尺寸在开轮前冻结。
  不强求遍历所有供应商，同一模型经千问／百炼两个入口不算独立评委。
- 既有 #233 的 17 个原子测试及正式 PNG 生命周期回归独立记录，不混进本次 48 题通过数。

最终交付必须带：输入／题目／已知答案及许可、逐题实际答案与状态、制作图／诊断图、后端和构建身份、
耗时与真实 usage／成本、失败与未测项、修复前后对照。区分 CV／模型成绩、工程 gate、真实链路、自动触发和用户验收。
冻结轮内不边测边改；终端后按根因聚类修复，用新变体复验，不把调参分数称为泛化。
